スラスターのコツ / このブラウザ版について

E + A で左に急旋回、Q + D で右に急旋回。E + D で左へ平行移動、Q + A で右へ平行移動します。BETA と ALPHA はラダーがありません。まずは LUSTER で、カーブの手前で減速する感覚をつかんでください。

ゲームパッド: A 加速 / X ターボ / B ブレーキ / 左スティック ラダー / LB・LT・RB・RT スラスター / Start 一時停止。

原作: Sato Tomokazu / Hover Racing (1997)。提供された HOVER_SOURCE と HOVER120 をもとに TypeScript で再実装。9コースの境界・高低差・床配置を HOVER.PAC から変換しています。機体TMD、路面TIM、背景、コースを原作データから復元。Three.jsで3D表示し、原作の60Hz推力・抵抗・スラスター・ダメージ式を移植しています。原作のSEQ/VABからBGMを再生し、原作HUD、噴射炎、POWER UPモデル、破壊スプライトを使用。START RACEで音声が有効になります。ジャンプ・着地・落下、GPの3戦進行、保持中のTAゴーストに対応。コース接地判定・CPU・キャラクターの動作は再実装です。CPUの操縦や物理の丸めには原作との差が残ります。PS1と完全一致の挙動は未対応です。

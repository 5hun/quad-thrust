# 原作照合メモ（2026-10-30）

照合対象は同梱の `HOVER_SOURCE` と `HOVER120`。実機の動画・PCMとの比較は実施していない。

| 対象           | 原作の根拠                                                                              | 修正内容と検証                                                                                                                                                                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 外壁の斜面     | `MAKEMAP.C` の `line` / `circle`、`CAR_CTR.C` の `car_getplate` / `car_gravide`         | 道路幅の外側にもある斜めタイルを接地対象にした。描画と衝突で同じ頂点生成処理を使用。左右・バンクあり／なしの面高さと接地を検証。                                                                                                                                          |
| コースアウト   | `CAR_CTR.C` の `car_getplate` / `car_gravide`                                           | 中心線距離だけの選択を路面四角形の座標判定へ変更。連続する近傍区間から選び、近接・交差する別の路面へ飛ぶ問題を修正。外側の落下基準は斜面の延長面ではなく原作の頂点高さと5000+2048のオフセット。Desert Goraで上の路面へ飛んでいた地点を回帰テスト化。                      |
| カメラ         | `GAME.C` の `view_set`                                                                  | 固定の高さと水平距離による配置を廃止。俯仰・旋回・バンクを含む回転で850の高さと追従距離を移す。開始時の距離も同じ軸に適用。通常姿勢・90度バンク・開始距離を数値検証。RED GP第1コースの自動走行60秒を30フレーム間隔で調べ、120サンプルすべてでカメラから機体への遮蔽なし。 |
| 床と外壁の描画 | `MAKEMAP.C` のプリミティブ生成                                                          | テクスチャ面の裏面を描かないよう頂点順とカリングを修正。別プリミティブだった暗いV字形の床裏面も追加。バンク時の外側への張り出しはXZだけでなく三次元の幅ベクトルで算出。                                                                                                   |
| 落下中の演出   | `CAR_CTR.C` の `car_action` / `car_resistance` / `car_gravide`、`GAME.C` の `game_draw` | カメラ固定を維持し、影を消す。落下中にも抵抗・重力・速度更新を実行し、速度に応じた風音を残す。ブースター音は解放。音量は実際のWeb Audioノードで検証。                                                                                                                     |
| EXIT           | `GP1_MAIN.C` の終了処理                                                                 | 更新ループ内でEXITが選ばれた場合、そのフレームの残りの描画と音声更新へ進まないよう修正。画面ボタンとキーボードの両方で終了後のオーバーレイが空のままになることを検証。                                                                                                    |
| VIEW RECORDS   | `OTR_MODE.C` の `view_records2`、`DRAW_SP.C` の `best_draw` / `total_draw`              | 機体名だけの表示を原作の24×16アイコンへ変更。CPU4台の走行背景、BEST LAP / TOTALの交互表示、決定による表示スキップを復元。全6機体の画像行が描かれることを検証。                                                                                                            |

## 検証範囲

- 型チェック、lint、整形、ビルド。
- ロジック・素材・課題・記録・入力リプレイ・カード・GP成績の既存テスト。
- 全9コースのプレイヤー3周、および4難易度×9コース×CPU3枠の完走。
- Chromium上の描画・音声、メニュー、カウントダウン・失敗・ゴール後の進行。

この検証は原作とのフレーム単位の完全一致を保証しない。固定小数点/GTEの丸め、描画順と半透明、CPU経路、SPUの補間と残響、日本語BIOSフォントなど、既存の差・近似はREADMEの「移植内容と原作との差」に記載している。カメラの遮蔽検証も、記載したコース・走行・サンプリング範囲に限る。

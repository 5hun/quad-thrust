# WHITE HARE 標準機

標準機（旧LUSTER）を、コードで制作したオリジナル機体WHITE HARE（ホワイトヘア）へ置き換えています。表示名を変更し、性能・機体ID・保存データは維持しています。内部モデルIDは `QUAD_01` のままです。

## デザイン

前後に絞った中央胴体、後方へ流れるキャノピー、前後左右の独立ポッド4基、薄い連結アームと後端の2枚の可動ラダーで構成します。断面を長手方向につないだローポリ形状で、機首・前方ポッド先端は横方向に幅を残したチゼル形状とし、横から見た薄いくさび形は維持しています。尾部は後方に絞っています。これは外観の変更で、空気抵抗など走行物理は変更しません。

全長・全幅は流線形試作の寸法を維持しています。中央胴体と4基のポッド、連結部には厚みを持たせています。ラダーを除く船体高は約1.90です（ゲーム内単位）。

キャノピーの最大幅は中央胴体の約75%です。キャノピーは独立した膨らみを作らず、中央胴体の上面と上側の斜面を切り分けた面として貼り分けています。ガラス面の全頂点は胴体の面上にあり、輪郭を変えません。ラダー本体の寸法は維持し、支点と噴射口の取付高さは厚い船体に追従します。噴流の形状・大きさと接地影は変更しません。

白を基調とする外装、濃い青のフレーム、前ポッドのアンバーの識別帯、ミント色の噴射口を使用します。通気口・番号・分割ブリッジなどの細かな装飾は省いています。

船体・ラダー・接地影の形状は `src/standard-machine.ts` で新規制作し、原作の機体メッシュ・テクスチャは使用していません。ラダーの前縁を後部デッキ上の支点に置き、操舵角に応じて後方の舵面が左右へ動きます。

## テクスチャ

ambientCGのCC0素材 [Metal032](https://ambientcg.com/view?id=Metal032) の1Kカラー画像とOpenGL法線画像を船体・フレーム・ラダーへ適用します。金属画像を明るい無彩色の微細な濃淡（0.9〜1.0）に変換して塗装色へ掛け合わせ、青灰色の着色を避けています。法線の強さは0.25に抑えています。キャノピーと発光部には金属画像を適用しません。キャノピーは専用にコードで生成する128×128の着色ガラステクスチャを使用し、青緑の濃淡と広い反射帯で塗装金属と区別します。外部素材には依存しません。長手方向に沿うUVを形状生成時に作成しています。

画像は `public/assets/machine/` に同梱し、実行中の外部通信は不要です。出典・ライセンス・取得元ファイル名は同フォルダーの `CREDITS.md` を参照してください。

## 噴射エフェクト

後方ジェットと4基のサイドスラスターの噴流には**原作標準機 `XVN_CAR` のモデル部品2・3をそのまま使用**します。独自の円錐や噴流形状は生成しません。新規船体とは分離した原作由来の素材です。

`src/renderer.ts` の `modelObject` から原作と同じ経路を呼び出し、形状・頂点色・単面描画・後方ジェットの深度先行処理・不透明度0.65・照明を共有します。回転・加速・ターボ時の大きさと照明変化・サイド噴射の点滅も既存の共通更新処理を使用します。後方ジェットは通常加速時に原作と同じ長さ5.44です。

原作PS1実機の表示そのものへの変更ではなく、このブラウザ版が他の原作機体に使用する描画処理との統一です。後方噴射を毎フレームの半透明描画で平滑化する既存のブラウザ向け近似も共通です。

### 粒子のように見える小片の確認

後方ジェット単体を4方向×8回転位相（計32条件）で描画し、破片数が0でも噴流の輪郭付近に1〜4ピクセルの独立した小片が出る条件を確認しました。噴流の表示は原作TMD由来のメッシュと深度専用メッシュの2つだけで、この小片は噴流メッシュの描画に由来します。独立した粒子エミッターは使用していません。衝突時の破片は `emitDebris` による別処理です。

半透明描画・毎フレーム表示・回転の平滑化は原作機体と共有しています。

## 新旧モデルの切り替え

通常はWHITE HAREを表示します。URLへ `?classicmachines` を追加すると、機体選択・走行・デモ・リプレイ・ゴーストのすべてで原作モデルとそのマウント位置・影を使用します。`classictrack`・`classiccourses` と併用できます。表示のみの切り替えで、機体名・性能・保存データは維持します。

## 組み込み

- `src/engine.ts` の標準機の表示モデルIDは `QUAD_01`。
- `src/renderer.ts` が船体・ラダー・接地影とCC0素材を組み合わせ、噴流は原作部品を読み込みます。
- 噴射口とラダーの位置は `STANDARD_MOUNTS` に定義。既存レンダラーに合わせた座標系で、Three.js座標へ `(x/100, -y/100, -z/100)` と変換。
- 機体選択画面とレース中のモデルは同じ生成処理を使用。

`npm run build` で配信用アセットとモジュールを再生成します。

今回の試作は標準機の外観置換です。他の4機体や共通エフェクト等は既存のものを使用し、原作モデルの変換・配信用データへの収録も継続します。

# マシンモデル作成の方針

今後の機体デザインに使う指針。個別機体の寸法・素材・実装は、それぞれの仕様書で管理する。

## シルエットと個性

- 機体の役割とモチーフを決め、色を付ける前に形で個性を出す。
- ローポリでも、面のつながりと前後の流れでレース機体らしさを作る。細かな装飾より、大きな形のまとまりを優先する。
- 流線形と尖った機首を同一視しない。横から見た薄さと、上から見た先端の横幅は別々に設計できる。
- 通気口・番号・補強部品を増やす前に、輪郭だけで魅力があるかを確認する。

## 胴体・キャノピー・ラダーの比率

- 全長・全幅、中央胴体の幅と厚み、ポッドの厚み、キャノピーの幅と高さを分けて調整する。
- 船体の量感は、ラダーやキャノピーだけを高くして補わない。ラダーを除いた胴体部分の高さで比較する。
- キャノピーは胴体との一体感を考える。膨らみを加える以外に、胴体面の一部をガラスとして貼り分ける方法も使える。
- 厚みを増したら、連結部・ラダー支点・噴射口の取付位置も合わせる。維持を指定された全長・全幅などは変えない。

## 配色と素材

- 主役となる塗装色と少量のアクセントを決め、配色で形のまとまりを保つ。
- テクスチャは色を決めるためではなく、細かな濃淡・凹凸・素材感を補うために使う。素材を貼った結果、意図した明るさや色味が失われていないかを見る。
- 金属、ガラス、フレーム、発光部は質感を作り分ける。ガラスに金属用テクスチャや法線マップをそのまま流用しない。
- 外部素材はCC0など利用条件を確認できるものを選び、出典・加工内容を残す。

## 操作が伝わる造形

- 4基のスラスターによる操作が外観から伝わるように、噴射口を前後左右に配置する。
- ラダーは見た目のヒレで終えず、適切な支点で操舵に連動させる。
- 噴流は既存の共通表示を使い、船体に合う取付位置と十分な大きさを確保する。
- 後方カメラでも、船体・ラダー・噴射口が見分けられる形にする。

## 作成と調整の進め方

1. まず1機を簡単な形でゲーム内に組み込み、輪郭と比率を決める。
2. 上面・側面・後方から確認し、その後に配色と素材を仕上げる。
3. 機体選択画面と走行画面の両方で見る。変更前後は同じ角度・距離・照明で比較し、操舵と噴射の動きも確認する。
4. 変更対象を絞り、合意済みの寸法・色・描画方法を引き継ぎながら調整する。
5. 見た目の特徴やモチーフから名前を考える。仕上げに不要な装飾や試作コードを整理する。

新旧の見た目を比較するときは `?classicmachines` を使う。外観の調整と走行性能の変更は分けて扱う。

# Hover Racing browser port — Three.js Edition

PS1版Hover Racingの提供ソースとデータを参考にしたTypeScript / Three.js版です。

## ディレクトリ構成

- `HOVER_SOURCE/`: 原作ソース
- `HOVER120/`: 原作データ
- `src/`: ブラウザ版のTypeScriptソース
- `dist/`: 配信用ファイル・アセット
- `tools/`: 原作データの抽出・変換ツール
- `tests/`: ゲームロジック・アセット・コースのテストスクリプト
- `extracted/`: 原作データの展開先（Git管理対象外）

以下のコマンドはすべてリポジトリのルートで実行します。

提供された `HOVER_SOURCE` と `HOVER120/HOVER.PAC` をもとにしたブラウザ移植です。前版の Canvas 2D 疑似3Dを撤去し、**Three.js r180 / WebGL 2** に変更しました。

## 起動

オンライン版は既存の本人限定 Sites URL を使用します。ローカル版は Python 3 で次を実行します。

```sh
python3 start-server.py
```

Windows は `py start-server.py` でも起動できます。PC内だけの `http://127.0.0.1:8765` をブラウザで開きます。終了は Ctrl+C。Three.jsを含む必要なファイルはすべて同梱し、ゲーム実行時にCDNへ接続しません。

**ES modulesと音声読み込みを使うため、前版と異なり `index.html` の直接ダブルクリックでは動きません。HTTP経由で開いてください。** WebGL 2対応ブラウザが必要です。

## TypeScript開発

ゲーム本体は `src/*.ts`、共通の状態・原作データ・ブラウザAPIの型は `src/types.d.ts` にあります。Node.js 22以降とnpmで開発できます。

```sh
npm ci
npm run typecheck  # strictモードで型チェック
npm run build      # src/*.ts → dist/*.js
npm test           # ビルドして既存の全テストを実行
npm start          # Python 3でローカルサーバーを起動
```

`npm ci`（または `npm install`）でコミット前のフックを有効にします。コミット時にはHuskyとlint-stagedがステージ済みファイルにPrettierを実行し、整形結果をコミットに含めます。`.prettierignore` の対象とPrettier非対応形式はスキップし、整形に失敗した場合はコミットを中止します。手動で整形する場合は `npm run format`、チェックのみの場合は `npm run format:check` を実行してください。

編集対象は `src/` です。`dist/` のゲーム本体JavaScriptはビルド生成物として同梱しているため、遊ぶだけなら引き続きPython 3のみで起動できます。TypeScriptを変更した場合は `npm run build` を実行し、生成された `dist/*.js` も一緒に更新してください。

`dist/` 内のHTML/CSS、原作データの変換ツールが生成するデータJavaScript・画像・音声、同梱Three.jsは引き続き配信用ファイルです。TypeScriptのビルドはこれらを削除・再生成しません。原作データの再生成には下記のPythonツールを使います。既存の検証ツールはCommonJS (`tests/*.cjs`) を維持しています。

物理・ルール・記録・トレーニングはブラウザの通常スクリプトとNode.jsの既存テストの双方で使うため、TypeScriptのnamespaceから従来のグローバルAPIとCommonJS APIを生成します。描画・音声・HUD・ゲーム画面はES modulesです。Three.jsの型定義は同梱r180に合わせています。実行時にnpmやCDNへの接続は不要です。

## 走行処理

`CAR_CTR.C` / `CAR_CTR2.C` の **60Hz固定更新**を基準にしています。

- 前後の独立した3D慣性ベクトルをPS1の元単位で保持。位置へは合算値 / 16 を反映。
- `CARS_PROPATIE` の6機体の重量、推力、速度減衰、ターボ、抵抗、耐久度、旋回値を使用。
- 主推進 / スラスター / 空気抵抗 / ブレーキの整数シフト式と、速度による推力変化を反映。
- ラダーの徐々に動く角度、明示的なスラスターyaw、BETA/ALPHAのラダーなし、ALPHAのターボなし、SUZUKIの4スラスター無効。
- 原作の蓄積ダメージ、自動修復、ターボの毎tick48ダメージ。
- `P` は進入時に6000回復、`J` は前後慣性へジャンプ衝撃、`>` はコース進行方向の加速衝撃。隣接する同じ文字の床では再発火しません。
- `*` の追加抵抗、`d` の継続ダメージ、`B` の致命ダメージ。前版で回復扱いしていた `+` は修正。
- 浮遊、重力、着地、空中姿勢、壁を飛び越えるコースアウト、機体同士の衝突。
- 原作のカメラ距離3500＋速度依存距離、約7度の下向き視点を参考にした追従カメラ。

## モードと操作

TIME ATTACK、PRACTICE、FREE RUN、Blue GP / Yellow GP / Red GP、TRAINING（LEVEL 1〜3・各5課題）。GPは各3コースで、1位なら次へ進み、敗北・破壊・落下時はそのコースを再挑戦できます。全コース・機体は最初から利用可能です。

タイムアタックはベスト完走のゴーストをコース・機体ごとにローカル保存し、より速く完走した場合のみ更新します。ゴーストには当たり判定がありません。記録は原作のTimeModeに合わせ、GP（PRACTICEを含む）とTIME ATTACKを分離し、各コースで機体を横断してBEST LAP / TOTALの上位6件を保存します。FREE RUNとTRAININGの走行は通常記録に混ざりません。旧版の混在したタイム記録は削除せず別キーで保持し、新ランキングには混入させません。ストレージ利用不可でもプレイできます。

| キー      | 操作                       |
| --------- | -------------------------- |
| Space / ↑ | 加速                       |
| ← / →     | ラダー                     |
| Q / A     | 左前 / 左後スラスター      |
| E / D     | 右前 / 右後スラスター      |
| Shift     | ターボ                     |
| S / ↓     | ブレーキ                   |
| W / X     | 空中の前傾 / 後傾          |
| Esc / P   | 一時停止                   |
| R         | フリーラン時のみコース復帰 |

E+Aで左急旋回、Q+Dで右急旋回。E+Dで左へ、Q+Aで右へ平行移動。

標準ゲームパッド: A加速、Xターボ、Bブレーキ、左右スティック軸でラダー、縦軸で空中姿勢、LB/LT/RB/RTでスラスター、Start一時停止。タッチ操作もあります。音はメニューの最初の操作で有効化し、SOUNDボタンでミュートできます。RETRO（内部320×240）とHDを切り替えられます。

## まだ原作と異なる点

原作バイナリのエミュレーションではなく、ソースと素材に基づく移植です。完全一致は保証しません。

- 接地・コース位置判定は変換後の区間と補間面を使用。原作のGTE、固定小数点行列、全ての衝突丸めを再現してはいません。斜面の力と姿勢制御も浮動小数点で再実装しています。
- Three.jsの深度バッファ・透視補正・照明を使用。RETROでは頂点を320×240の画素へ丸め、アフィンUVとRGB各5bitの色量子化を適用します。原作の描画順、GTEの演算丸め、VRAMの半透明色演算は完全再現していません。背景は原作の画面座標によるパノラマ・地上帯の描画式をThree.jsへ移植しています。
- CPUの操縦判断は新規実装。プレイヤーと同じ運動式で走行し、落下後は復帰します。SUZUKIは原モデルの関節階層とDASHテーブルを使用しますが、停止時の遷移と足の接地補正には差があります。
- 効果音の素材は原作ですが、SPUのADSR・リバーブ・発音タイミングと完全一致しません。BGMは元のSEQイベント・テンポ・楽器・VABサンプル・ループをWeb Audioで再生します。音程補間、ADSR包絡線、リバーブはPS1 SPUと完全一致しません。
- タイムアタックは原作と同じ3周制。GPの進行は実装しましたが、原作の解禁・セーブカード仕様は未移植。2P画面分割、原作形式のリプレイ再生は未対応。

## PRACTICE・TRAINING・記録

名称をSINGLE RACEからPRACTICE、GREENからBlue GPへ修正しました。PRACTICEは原作のGameMode 1に対応し、コース選択式のCPU3台・3周レースです。通常の対戦機体は0〜3番を昇順に選び、使用機体を除いた先頭3台です。隠し機体の場合もこの選択則を使います。

TRAININGは `TRAINIG.C` の15課題を実装し、HOVER.PACのTSTG/TPTN専用コースを変換しています。オープンコース末尾から始点へ架空の道路を作らず、各区間の元の終点を保持します。3-5の空のPAT指定は原作のatoiと同じ0として解釈します。

- LEVEL 1: スラスター一回転、ゴール、ゴール、壁接触禁止、ゴール。制限60 / 12 / 12 / 18 / 18秒。
- LEVEL 2: 180 Km/h維持＋壁接触禁止、赤床回避、200 Km/h維持、壁接触禁止＋1位、壁接触禁止。制限15 / 16 / 20 / 25 / 20秒。
- LEVEL 3: ノーダメージ＋1位、1位、ノーダメージ、230 Km/h維持、壁接触禁止＋常時1位。制限12 / 27 / 18 / 25 / 33秒。
- 2-1 / 2-3 / 3-4 / 3-5はカウントダウン中から自動走行。1面ごとの敵数、開始位置、ゴール床、停止床、ジャンプ床の垂直慣性リセットを反映。
- 原作B.SEQをTRAININGのBGMとして再生。原作フォントの残り時間HUD、COMPLETE / MISS、失敗理由、同課題リトライ、次の課題、機体別クリア保存に対応。

単体テストは15課題の各条件、14コースの実際のg床でのゴールイベント、最低速度課題のローリングスタート、六件ランキングとカテゴリ分離を検証。Chromiumで15課題の開始、4課題のローリング開始、成功・失敗・次課題・再挑戦・機体別保存、GP進行とモバイル表示を確認しました。成功・失敗の画面遷移テストにはブラウザ内だけの状態注入を使用し、全課題を実操作でクリアした検証ではありません。

CPUの操縦はブラウザ版の再実装です。原作のCPU経路選択・加速補正、固定小数点物理、解禁条件・メモリーカード・プレイヤー名入力まで完全一致するものではありません。ランキングにはタイムと使用機体を保存します。

## 原作照合後の走行修正

- 通常レースの周回判定を累積距離から `g` 床への進入に変更。原作の `line_position > last_goal + 32` に合わせ、コースの行位置を追跡してスタート直後・逆走・短い往復での重複計測を防ぎます。TRAININGの課題用ゴール判定は別に維持します。
- 全車の移動後、プレイヤー対CPUとCPU対CPUの各組を一度ずつ衝突判定します。衝突は3D球判定・重量補正後の反発とダメージ・CPUへのダメージ免除を反映しています。原作との更新順序と丸めの差は残ります。
- GP / PRACTICEに4段階のCPU難易度を追加し、ブラウザに選択を保存します。`GAME.C` の4×9レベル表、`CAR_CTR.C` の出走枠別最高速度、レベル2以上の追加推力、10秒経過後の進行位置差による加速補正を反映しました。操縦経路・旋回判断・低速時の壁回避は変換済みコース向けの適応処理であり、原作の `car_control` 全体の移植ではありません。TRAININGのCPU設定は課題ごとの従来設定を使います。
- カメラは描画FPS依存の10%補間を廃止し、60Hzで原作のヨー・ピッチ・ロール追従量と速度による距離の増減を更新。一時停止中は追従も停止します。視点行列全体やスタート時のカメラ演出は完全再現ではありません。

検証には、ゴール床なしでは周回しないこと、32行の再計測制限、CPU同士の衝突、CPU速度・追加推力、カメラの角度境界・傾き・距離を追加しました。PS1の固定小数点物理、原作形式のリプレイ、解禁、2P、メニュー・演出、SPUの完全再現などは引き続き未対応です。

追加検証結果: 4難易度×9コース×CPU3枠の108通りで、それぞれ単独走行による3周完走を確認しました（通常レースと同じ落下時の復帰を許可）。CPU間衝突は別の単体テストで確認しています。Chromiumでは9コース・6機体、走行・GP・TRAINING・モバイル幅に加え、難易度の保存と実際のCPUレベルへの反映、一時停止中のカメラ停止を確認しました。ページエラーなし。

## 衝突・接地・描画・音声の追加照合

- `CAR_CTR.C` の機体間衝突を3D距離512未満で判定し、上下の反発、重量補正後のダメージ、CPUのダメージ免除を反映。同位置に重なった場合もダメージ判定します。
- 接地高さを現在の床セルの頂点から求める平面に変更。床下へ落ちた機体が接地補正で復帰する問題を修正し、原作の着地・コースアウト閾値を反映しました。`CAR_CTR2.C` の斜面力にY成分を加え、面法線による姿勢制御に40単位の不感帯と角度ステップを反映しました。
- 壁の余白を道路幅比率から固定距離へ変更。壁側の高さで飛び越えを判定し、壁に沿う3Dベクトルへの射影と反発を使用します。影も接地面の法線に合わせます。
- RETROで320×240の頂点丸め、アフィンUV、RGB各5bit量子化を適用。HDは従来の透視補正を使用します。深度バッファ・照明・描画順は引き続きThree.jsです。
- 最大64個・48tickの三角形破片に重力を適用。爆発の画像・更新周期・縮尺・機体の非表示期間を修正。乱数列はブラウザ用の決定的な列であり、原作と同じ配置にはなりません。
- SUZUKIの前腕・手・膝・足を正しい親子階層に変更し、`OMAKE.C` のDASH配列と補間式を使用。TRAININGのCOMPLETE / MISSは原作の文字モデルと出現間隔・接近・回転式で表示し、2秒後に結果操作を表示します。
- SE.VHのADSR・音量・ループ情報を復元。BGMと効果音の包絡線をAudioWorklet内で44.1kHzのSPUレートに従って更新します。低パワー警告とダメージ床音は持続音の開始／停止に変更。再生中のBGMの音量・パン変更、ターボ時の後部噴射音だけの音程変更も反映しました。
- 原作のHALL・深さ64の設定に基づき残響経路を追加しました。残響はWeb Audioの畳み込みによる近似で、SPUのリバーブRAM演算・ガウス補間・24音発音制限は未再現です。ADSRの参照資料は[PSX-SPXのSPU仕様](https://psx-spx.consoledev.net/soundprocessingunitspu/)です。

`npm test` に3D衝突・斜面・着地・壁幅・破片寿命・ADSRレジスタの回帰検証を追加。全9コースと4難易度×CPU3枠の完走確認に加え、ChromiumでRETRO/HDのシェーダー、破片、爆発、SUZUKI、3D結果文字、実際の音声信号、持続音の開始／停止を検証します。ブラウザテストはローカルサーバーを起動し、インストール済みPlaywrightを使って `npm run test:browser -- <Playwrightのモジュールパス> <Chromiumの実行ファイル> <URL>` で実行できます。

固定小数点の位置・行列・コース選択、全ての壁形状との一致、照明と半透明の演算、全てのメニュー・開始・結果演出について、PS1実機との完全一致を確認したものではありません。

音切れの回帰対策: 自然終了したサンプルや停止したBGMは、接続の解除に加えてAudioWorkletへ終了メッセージを送ります。常に`true`を返すプロセッサが再生終了後も残り、音声処理負荷が蓄積する問題を修正しました。2000個のプロセッサ終了テストと、ブラウザでBGMに多数の効果音を重ねる60秒の連続再生テストを追加しています。

爆発の描画順: `DRAW_SP.C` の `GsSortSprite(..., ot, 0)` に合わせ、爆発スプライトは深度テスト・深度書き込みを無効にして3D物体の後に描画します。機体の手前へ不透明な面を置くブラウザ回帰テストで、爆発が隠れないことを画素比較で検証します。

## 床効果・CPUの斜面力・スタートカメラの再照合

`CAR_CTR.C` の `car_chipeffect`、`CAR_CTR2.C` の `car_bank`、`GAME.C` の `view_set` / `start_count` を照合し、次の相違を修正しました。

- 空中でジャンプ床へ入っても発動済みとして記憶せず、同じ床の上で接地した時にジャンプします。回復床・加速床は原作どおり、空中で入ると接地しても再発動しません。
- TRAININGのゴール床・停止床は接地を条件にせず、空中での進入でも課題へ通知します。
- 通常レースのCPUはダメージ床 `d` と減速床 `*` の影響を受けません。致命床 `B` は引き続きCPUにも適用します。TRAININGのCPUは従来の別制御で、通常レースのCPUレベルを使用していません。
- 加速床 `>` は道路中央の向きではなく、走行中の床セルの縦方向の辺から前後の慣性へ衝撃を与えます。カーブ・幅の変化・左右で異なる高低差を含みます。
- 接地したCPUにも原作の斜面力を適用します。
- スタートの残り300フレームから距離を縮め、残り120フレームまでは `max(0, start_count-120)*16` による旋回を追従目標へ反映します。スタート時の追従角は原作の初期値0から開始します。カウントを整数フレームで更新し、残り180 / 120 / 60フレームでビープ、0で走行開始とします。

回帰テストには空中進入から接地した各床の発動、CPUの床効果と斜面力、幅・傾斜が変化する加速床、スタートの旋回量を追加しました。ブラウザテストでは実際のカメラ距離と旋回目標も検証します。カメラの視点行列全体、GTE・固定小数点演算、CPU操縦、解禁・セーブカード・2P・原作形式のリプレイなど、前述の未移植・近似部分は残ります。

### レース後UIの原作照合

`GAME.C` の `pause()` に合わせ、停止した走行画面上の原作フォントでCONTINUE / RESTART / EXITを表示し、上下・決定・キャンセルとゲームパッドの項目選択を追加しました。通常ゴールは `goal_count()` のFINISH、GPは順位文字モデルを8tick間隔で出現させ、Z=5000→4000・200ずつの接近と回転を適用し、3秒後に結果操作へ進みます。TRAININGの既存COMPLETE / MISS演出は維持しています。

GPの破壊・落下後、および完走後3秒の順位表示を終えた敗北時には、`sel_continue()` の立体CONTINUE?とYES/NOを表示します。左右入力で16tickの回転中点で選択を切り替え、YESは同じ戦をリトライ、NOは終了します。キーボード・ゲームパッド・タッチ操作を実装しました。

TIME ATTACK / PRACTICEの完走後に、原作45文字から3文字を選ぶ立体NAME ENTRY、ラップ一覧、BESTLAP RECORDS / TOTAL RECORDSを追加しました。記録は名前付きで保存し、旧記録の名前は---として表示します。元のCAR_MINI画像をランキングへ表示し、ENTRY1.SEQを再生します。記録一覧は決定で切り替え、キャンセルで選択画面へ戻ります。

GPは各戦1位の順位表示3秒後に次戦へ自動進行し、3戦優勝後に原作STAFF2.TXTのクレジットを表示します。`draw_name()` のペア表示・幕・スライド・スタッフ項目別表示時間、SAMPLE19.SEQ、最大68秒・決定/Startによるスキップを反映しています。GPのベストラップ/トータルはコースごとに最速の完走を蓄積し、終了時に一度だけ名前を入力して全対象コースの記録へ保存します。原作の青→赤の成績背景で、各コースのBESTLAP / TOTALを順番に表示します。CONTINUEのNOから終了する場合も、完走したコースの成績を登録します。

TRAININGは2秒のCOMPLETE後に同じ課題の選択へ戻り、MISS後は同じ課題を自動リトライします。落下時は原作の256tick待機中に機体が落ち続け、カメラを固定します。通常レースの失敗は機体選択に戻ります。従来のブラウザ向け結果カードは撤去しました。完走後とスタッフ表示の背景は保存したプレイヤー軌跡を再生します。

日本語のスタッフ文字は提供データにPS1 BIOSフォントが含まれないためブラウザフォントです。原作形式のリプレイデータは未対応で、背景の再走行は10Hzで記録した全車の軌跡をフレームごとに補間します。原作の物理を再実行する形式やカメラ切り替えまで完全再現するものではありません。GP成績背景のGouraud色演算、文字の照明・描画丸め、スタッフ画面の日本語字形にも差が残ります。

`npm run test:postrace -- <Playwrightのモジュールパス> <Chromiumの実行ファイル> <URL>` は、ポーズ・GP落下/破壊/敗北からのYES/NO、全3戦勝利→スタッフ→3コース分の名前付き記録登録、通常完走の名前入力・記録画面、TRAININGの成功選択復帰・失敗自動再挑戦を検証します。完走・失敗状態はテスト内だけで注入しています。

### スタッフ表示の滑らかさ・文字崩れの修正

リプレイは保存された10Hzの軌跡を描画時刻で補間し、位置・姿勢・カメラとCPU機体を更新します。スタッフや記録の表示段階が変わっても再生時刻はリセットしません。日本語スタッフ行は16ピクセルの固定セルへ一度描画してキャッシュし、画面外へ出るときはクリッピングのみ行います。画面内のX座標に応じた自動改行による、スライド中の文字崩れを修正しました。

`npm run test:credits -- <Playwrightのモジュールパス> <Chromiumの実行ファイル> <URL>` で全38行の画面外スライド・全スタッフ表示段階の描画を検証します。`test:postrace`は実際に加速して記録したGP走行で、クレジットの連続40描画フレームが更新されることも検証します。保存データは10Hzのままなので、固定小数点物理の完全なリプレイではありません。

# Hover Racing browser port — Three.js Edition

PS1版Hover Racingの提供ソースとデータを参考にしたTypeScript / Three.js版です。

## ディレクトリ構成

- `HOVER_SOURCE/`: 原作ソース
- `HOVER120/`: 原作データ
- `src/`: ブラウザ版のTypeScriptソース
- `dist/`: 配信用ファイル・アセット
- `tools/`: 原作データの抽出・変換ツール
- `tests/`: ゲームロジック・アセット・コースのテストスクリプト
- `extracted/`: 原作データの展開先（Git管理対象外）

以下のコマンドはすべてリポジトリのルートで実行します。

提供された `HOVER_SOURCE` と `HOVER120/HOVER.PAC` をもとにしたブラウザ移植です。前版の Canvas 2D 疑似3Dを撤去し、**Three.js r180 / WebGL 2** に変更しました。

## 起動

オンライン版は既存の本人限定 Sites URL を使用します。ローカル版は Python 3 で次を実行します。

```sh
python3 start-server.py
```

Windows は `py start-server.py` でも起動できます。PC内だけの `http://127.0.0.1:8765` をブラウザで開きます。終了は Ctrl+C。Three.jsを含む必要なファイルはすべて同梱し、ゲーム実行時にCDNへ接続しません。

**ES modulesと音声読み込みを使うため、前版と異なり `index.html` の直接ダブルクリックでは動きません。HTTP経由で開いてください。** WebGL 2対応ブラウザが必要です。

## TypeScript開発

ゲーム本体は `src/*.ts`、共通の状態・原作データ・ブラウザAPIの型は `src/types.d.ts` にあります。Node.js 22以降とnpmで開発できます。

```sh
npm ci
npm run typecheck  # strictモードで型チェック
npm run build      # src/*.ts → dist/*.js
npm test           # ビルドして既存の全テストを実行
npm start          # Python 3でローカルサーバーを起動
```

編集対象は `src/` です。`dist/` のゲーム本体JavaScriptはビルド生成物として同梱しているため、遊ぶだけなら引き続きPython 3のみで起動できます。TypeScriptを変更した場合は `npm run build` を実行し、生成された `dist/*.js` も一緒に更新してください。

`dist/` 内のHTML/CSS、原作データの変換ツールが生成するデータJavaScript・画像・音声、同梱Three.jsは引き続き配信用ファイルです。TypeScriptのビルドはこれらを削除・再生成しません。原作データの再生成には下記のPythonツールを使います。既存の検証ツールはCommonJS (`tests/*.cjs`) を維持しています。

物理・ルール・記録・トレーニングはブラウザの通常スクリプトとNode.jsの既存テストの双方で使うため、TypeScriptのnamespaceから従来のグローバルAPIとCommonJS APIを生成します。描画・音声・HUD・ゲーム画面はES modulesです。Three.jsの型定義は同梱r180に合わせています。実行時にnpmやCDNへの接続は不要です。

## 原作から復元したデータ

- 9コースの直線・楕円境界、高低差、全床パターン、側壁4列。`MAKEMAP.C` の構成に合わせてメッシュ化。
- LUSTER / EXCEL / BETA / JUSTER / ALPHA の元のTMDモデル。各モデルの本体、ラダー、後部噴射、4基のスラスター、影を個別に配置。
- 隠しキャラクター **SUZUKI** の `YAKA_MAN.TMD`。前版の「SPECIAL」という仮名と代替機体を修正。
- TMDの頂点・法線・面・色・UV、`CARS.TIM` のテクスチャ。VRAM上のページ・CLUTを解決してPNG化。
- `ROAD.TIM` / `KABE.TIM` から24種の床・側壁テクスチャ。背景も元のTIM画像。
- `SE.VH` / `SE.VB` の11効果音プログラム。SPU ADPCMをPCM WAVに変換し、Web Audioで再生。

## 走行処理

`CAR_CTR.C` / `CAR_CTR2.C` の **60Hz固定更新**を基準にしています。

- 前後の独立した3D慣性ベクトルをPS1の元単位で保持。位置へは合算値 / 16 を反映。
- `CARS_PROPATIE` の6機体の重量、推力、速度減衰、ターボ、抵抗、耐久度、旋回値を使用。
- 主推進 / スラスター / 空気抵抗 / ブレーキの整数シフト式と、速度による推力変化を反映。
- ラダーの徐々に動く角度、明示的なスラスターyaw、BETA/ALPHAのラダーなし、ALPHAのターボなし、SUZUKIの4スラスター無効。
- 原作の蓄積ダメージ、自動修復、ターボの毎tick48ダメージ。
- `P` は進入時に6000回復、`J` は前後慣性へジャンプ衝撃、`>` はコース進行方向の加速衝撃。隣接する同じ文字の床では再発火しません。
- `*` の追加抵抗、`d` の継続ダメージ、`B` の致命ダメージ。前版で回復扱いしていた `+` は修正。
- 浮遊、重力、着地、空中姿勢、壁を飛び越えるコースアウト、機体同士の衝突。
- 原作のカメラ距離3500＋速度依存距離、約7度の下向き視点を参考にした追従カメラ。

## モードと操作

TIME ATTACK、PRACTICE、FREE RUN、Blue GP / Yellow GP / Red GP、TRAINING（LEVEL 1〜3・各5課題）。GPは各3コースで、1位なら次へ進み、敗北・破壊・落下時はそのコースを再挑戦できます。全コース・機体は最初から利用可能です。

タイムアタックはベスト完走のゴーストをコース・機体ごとにローカル保存し、より速く完走した場合のみ更新します。ゴーストには当たり判定がありません。記録は原作のTimeModeに合わせ、GP（PRACTICEを含む）とTIME ATTACKを分離し、各コースで機体を横断してBEST LAP / TOTALの上位6件を保存します。FREE RUNとTRAININGの走行は通常記録に混ざりません。旧版の混在したタイム記録は削除せず別キーで保持し、新ランキングには混入させません。ストレージ利用不可でもプレイできます。

| キー      | 操作                       |
| --------- | -------------------------- |
| Space / ↑ | 加速                       |
| ← / →     | ラダー                     |
| Q / A     | 左前 / 左後スラスター      |
| E / D     | 右前 / 右後スラスター      |
| Shift     | ターボ                     |
| S / ↓     | ブレーキ                   |
| W / X     | 空中の前傾 / 後傾          |
| Esc / P   | 一時停止                   |
| R         | フリーラン時のみコース復帰 |

E+Aで左急旋回、Q+Dで右急旋回。E+Dで左へ、Q+Aで右へ平行移動。

標準ゲームパッド: A加速、Xターボ、Bブレーキ、左右スティック軸でラダー、縦軸で空中姿勢、LB/LT/RB/RTでスラスター、Start一時停止。タッチ操作もあります。音はSTART RACEの操作で有効化し、SOUNDボタンでミュートできます。RETRO（内部320×240）とHDを切り替えられます。

## まだ原作と異なる点

原作バイナリのエミュレーションではなく、ソースと素材に基づく移植です。完全一致は保証しません。

- 接地・コース位置判定は変換後の区間と補間面を使用。原作のGTE、固定小数点行列、全ての衝突丸めを再現してはいません。斜面の力と姿勢制御も浮動小数点で再実装しています。
- Three.jsの深度バッファ・透視補正・照明を使用。PS1のポリゴン揺れ、アフィンUV、描画順、VRAM色演算は再現していません。背景は原作の画面座標によるパノラマ・地上帯の描画式をThree.jsへ移植しています。
- CPUの操縦判断は新規実装。プレイヤーと同じ運動式で走行し、落下後は復帰します。SUZUKIは原モデルを階層配置していますが、走行アニメーションは簡易版です。
- 効果音の素材は原作ですが、SPUのADSR・リバーブ・発音タイミングと完全一致しません。BGMは元のSEQイベント・テンポ・楽器・VABサンプル・ループをWeb Audioで再生します。音程補間、ADSR包絡線、リバーブはPS1 SPUと完全一致しません。
- タイムアタックは原作と同じ3周制。GPの進行は実装しましたが、原作の解禁・セーブカード仕様は未移植。2P画面分割、原作形式のリプレイ再生は未対応。

## 原作照合による音・HUD・エフェクト修正

- `DRAW_SP.C` の320×240座標と `flamebuff_init` の文字コピーを復元。原作の数字・文字、速度÷2、TOTAL、3行のラップタイム、BEST LAP、順位、縦型POWER、左上マップ、LAST/FINAL LAP、逆走警告。マップのシルエットはコース形状から再描画しています。
- `CAR_CTR.C` の後部噴射の隔フレーム描画、64フレームの残り火、ターボ時80/64倍、横スラスターの逆位相点滅。POWER UPはOTHER.TMD object 0を31/16から縮小し、45度ずつ回転。
- 5秒のスタート処理、ALP_0_9.TMDの立体数字、BOMB.TIMの破壊演出と5秒の結果待ち、パワー不足警告音。効果音の発音キーも原作呼び出しに合わせました。
- 画面は4:3。HDでも構図を保ち、HUDは原作解像度で拡大します。

メニュー・結果画面はブラウザ向けUIです。原作の完全なメニュー遷移、爆発時の破片物理、全てのリプレイ演出や画面分割は引き続き未対応です。

## 地上背景の復元

`COURCE.C` の sfname を照合し、未使用だった地上15画像を追加しました。都市はSEA01系の海面、岩場はROCK_D系、氷原はSEA_KEI系、霧の街はTOWN系、砂漠はSABA_T系です。既存の単色地面と円筒形の空を撤去し、`make_back_tmd` / `back_draw` の6列×3段の台形、128ピクセル単位の横移動、1920ピクセルの空パノラマ、原画像の背景色をThree.jsの専用背景パスで描画します。地上は景観用で当たり判定はありません。都市の5本のサーチライトも原作の位置・振幅・周期から再現しました。

背景検証: 5テーマ・9コースの描画、画像読み込みエラーなし、上下の視点変化、都市限定の5本の光柱をChromiumで確認。原作SPU/GTEの完全エミュレーションではないため、色演算・半透明・丸めには引き続き差があります。

## PRACTICE・TRAINING・記録

名称をSINGLE RACEからPRACTICE、GREENからBlue GPへ修正しました。PRACTICEは原作のGameMode 1に対応し、コース選択式のCPU3台・3周レースです。通常の対戦機体は0〜3番を昇順に選び、使用機体を除いた先頭3台です。隠し機体の場合もこの選択則を使います。

TRAININGは `TRAINIG.C` の15課題を実装し、HOVER.PACのTSTG/TPTN専用コースを変換しています。オープンコース末尾から始点へ架空の道路を作らず、各区間の元の終点を保持します。3-5の空のPAT指定は原作のatoiと同じ0として解釈します。

- LEVEL 1: スラスター一回転、ゴール、ゴール、壁接触禁止、ゴール。制限60 / 12 / 12 / 18 / 18秒。
- LEVEL 2: 180 Km/h維持＋壁接触禁止、赤床回避、200 Km/h維持、壁接触禁止＋1位、壁接触禁止。制限15 / 16 / 20 / 25 / 20秒。
- LEVEL 3: ノーダメージ＋1位、1位、ノーダメージ、230 Km/h維持、壁接触禁止＋常時1位。制限12 / 27 / 18 / 25 / 33秒。
- 2-1 / 2-3 / 3-4 / 3-5はカウントダウン中から自動走行。1面ごとの敵数、開始位置、ゴール床、停止床、ジャンプ床の垂直慣性リセットを反映。
- 原作B.SEQをTRAININGのBGMとして再生。原作フォントの残り時間HUD、COMPLETE / MISS、失敗理由、同課題リトライ、次の課題、機体別クリア保存に対応。

単体テストは15課題の各条件、14コースの実際のg床でのゴールイベント、最低速度課題のローリングスタート、六件ランキングとカテゴリ分離を検証。Chromiumで15課題の開始、4課題のローリング開始、成功・失敗・次課題・再挑戦・機体別保存、GP進行とモバイル表示を確認しました。成功・失敗の画面遷移テストにはブラウザ内だけの状態注入を使用し、全課題を実操作でクリアした検証ではありません。

CPUの操縦はブラウザ版の再実装です。原作のCPU経路選択・加速補正、固定小数点物理、クリア時の3D文字演出、解禁条件・メモリーカード・プレイヤー名入力まで完全一致するものではありません。ランキングにはタイムと使用機体を保存します。

## 原作照合後の走行修正

- 通常レースの周回判定を累積距離から `g` 床への進入に変更。原作の `line_position > last_goal + 32` に合わせ、コースの行位置を追跡してスタート直後・逆走・短い往復での重複計測を防ぎます。TRAININGの課題用ゴール判定は別に維持します。
- 全車の移動後、プレイヤー対CPUとCPU対CPUの各組を一度ずつ衝突判定します。衝突の力学自体はブラウザ版の近似です。
- GP / PRACTICEに4段階のCPU難易度を追加し、ブラウザに選択を保存します。`GAME.C` の4×9レベル表、`CAR_CTR.C` の出走枠別最高速度、レベル2以上の追加推力、10秒経過後の進行位置差による加速補正を反映しました。操縦経路・旋回判断・低速時の壁回避は変換済みコース向けの適応処理であり、原作の `car_control` 全体の移植ではありません。TRAININGのCPU設定は課題ごとの従来設定を使います。
- カメラは描画FPS依存の10%補間を廃止し、60Hzで原作のヨー・ピッチ・ロール追従量と速度による距離の増減を更新。一時停止中は追従も停止します。視点行列全体やスタート時のカメラ演出は完全再現ではありません。

検証には、ゴール床なしでは周回しないこと、32行の再計測制限、CPU同士の衝突、CPU速度・追加推力、カメラの角度境界・傾き・距離を追加しました。PS1の固定小数点物理、原作形式のリプレイ、解禁、2P、メニュー・演出、SPUの完全再現などは引き続き未対応です。

追加検証結果: 4難易度×9コース×CPU3枠の108通りで、それぞれ単独走行による3周完走を確認しました（通常レースと同じ落下時の復帰を許可）。CPU間衝突は別の単体テストで確認しています。Chromiumでは9コース・6機体、走行・GP・TRAINING・モバイル幅に加え、難易度の保存と実際のCPUレベルへの反映、一時停止中のカメラ停止を確認しました。ページエラーなし。

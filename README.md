# Hover Racing browser port — Three.js Edition

PS1版Hover Racingの提供ソース `HOVER_SOURCE` とデータ `HOVER120/HOVER.PAC` に基づく、TypeScript / Three.js r180 / WebGL 2のブラウザ移植です。

## 起動

オンライン版は既存の本人限定Sites URLを使用します。ローカル版はリポジトリのルートで次を実行し、ブラウザで `http://127.0.0.1:8765` を開きます。

```sh
python3 start-server.py
```

Windowsでは `py start-server.py` も使用できます。終了はCtrl+C。遊ぶだけならPython 3とWebGL 2対応ブラウザで起動でき、Three.jsを含む必要なファイルはすべて同梱しています。実行時にnpmやCDNへの接続は不要です。

ES modulesと音声読み込みを使うため、`index.html` の直接ダブルクリックでは動きません。HTTP経由で開いてください。

## モードと操作

| モード      | 内容                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| GRANDPRIX   | Blue / Yellow / Red GP。各3コースで、1位なら次戦へ進みます。敗北・破壊・落下時は同じ戦を再挑戦できます。  |
| PRACTICE    | コース選択式のCPU3台・3周レース。                                                                         |
| TIME ATTACK | 3周のタイム計測。保持中の同一コースのTAリプレイがあれば、当たり判定のないゴーストと対戦します。           |
| FREE RUN    | 自由走行。コース復帰が可能です。                                                                          |
| TRAINING    | LEVEL 1〜3・各5課題。機体別のクリア状態を記録します。成功後は課題選択へ戻り、失敗時は自動で再挑戦します。 |

最初はBlue GP・PRACTICEと通常4機体を利用できます。Blue GPクリアでYellow GP、Yellow GPクリアでRed GP、Red GPクリアでALPHAを解禁します。通常5機体それぞれで全15トレーニングをクリアし、課題選択を抜けるとSUZUKIを解禁します。コース選択では全9コースを利用できます。

メニューは方向キーで選択、Enter / Zで決定、Esc / Xで戻ります。OPTIONから記録閲覧・音楽・リプレイ・メモリーカードを利用できます。HELPには原作の説明本文と機体・操作の立体表示があります。

| キー      | 走行操作                   |
| --------- | -------------------------- |
| Space / ↑ | 加速                       |
| ← / →     | ラダー                     |
| Q / A     | 左前 / 左後スラスター      |
| E / D     | 右前 / 右後スラスター      |
| Shift     | ターボ                     |
| S / ↓     | ブレーキ                   |
| W / X     | 空中の前傾 / 後傾          |
| Esc / P   | 一時停止                   |
| R         | フリーラン時のみコース復帰 |

E+Aで左急旋回、Q+Dで右急旋回。E+Dで左へ、Q+Aで右へ平行移動します。

標準ゲームパッドはAで加速、Xでターボ、Bでブレーキ、左右スティックの横軸でラダー、縦軸で空中姿勢、LB/LT/RB/RTでスラスター、Startで一時停止。メニューは方向・A・B・Startで操作します。走行中はタッチ操作にも対応しています。

画面直下の常時表示パネルに、全画面・画質・音声・セーブデータ入出力をまとめています。全画面中はゲーム画面だけを表示します。画面は4:3で、RETRO（内部320×240）とHDを切り替えられます。音声は最初の操作で有効になり、SOUNDボタンでミュートできます。CPU難易度はゲーム内の OPTION → MEMORY CARD → SLOT → GAME LEVEL で設定します。メニューの切り替え・決定・戻ると、一時停止はキーボード／ゲームパッドで操作します。

`EXIT`は画面を黒くして音声と更新ループを停止します。ブラウザタブは閉じないため、再起動にはページを再読み込みしてください。

## 記録・リプレイ・保存

- 記録はGP（PRACTICEを含む）とTIME ATTACKを分離し、各コースで機体を横断したBEST LAP / TOTALの上位6件を名前付きで保持します。FREE RUNとTRAININGは通常記録に含めません。
- リプレイは60Hzの操縦入力を記録し、物理・CPU・衝突処理を再実行します。保持するのはセッション内の1組で、`OPTION → VIEW REPLAY`から再生できます。
- ゴーストありのTAでは、厳密に速く完走した場合だけ対戦記録を更新します。別コースやGP / PRACTICEの完走は保持記録を置き換えます。コースを選ぶだけ、または未完走では置き換えません。SUZUKI同士は単独TAとして扱います。ゴーストは原作と同じ条件で自動的に出現します。
- `OPTION → MEMORY CARD → SLOT 1 / SLOT 2`からシステムデータとリプレイを保存・読込できます。Yellow GP解禁後は原作の特別リプレイ3件、Blue GPクリア後はENDINGも利用できます。
- 記録・解禁・課題・名前・設定はRAM上で更新し、手動保存またはAUTO SAVEで指定スロットへ保存します。AUTO SAVEは機体／課題選択を抜けてタイトルメニューへ戻る時に実行します。AUTO LOADはスロット順に有効な設定を読み込みます。未保存の進捗は再起動で失われます。
- 仮想カードはブラウザのローカル保存領域を使います。画面外のブラウザ設定から、原作の `BNYedg01299HoverVer1` に相当する8KBゲームデータを `.bin` で書き出し／取り込みできます。PS1カード全体のMCRイメージではありません。不正データや容量不足の場合、保存済みカードは変更しません。
- 旧ブラウザ保存データは削除せず、初回にSLOT 1へ移行します。利用するにはLOAD SYSTEM DATAで読み込み、必要ならAUTO LOADをONにしてSAVE SYSTEM DATAしてください。旧版の混在タイム記録や座標形式ゴーストは、現在のランキング・入力リプレイには使用しません。

原作ソースとの今回の照合・修正内容と検証範囲は [原作照合メモ](docs/fidelity-audit.md) に記載しています。外壁の斜面への接地、近接路面の選択、カメラの回転を含む視点位置、床裏面、落下時の風音、EXIT後の描画停止、記録閲覧の機体アイコン・走行背景を修正しました。

## 移植内容と原作との差

9コースとトレーニング専用コース、6機体のTMDモデル、床・側壁・背景・HUD・HELPの素材、効果音と全12曲のSEQ / VAB音源を使用しています。走行は `CAR_CTR.C` / `CAR_CTR2.C` の60Hz固定更新を基準とし、機体特性・床効果・衝突・浮遊・着地・周回判定を実装しています。メニュー、解禁、結果、スタッフ表示、入力形式リプレイ、仮想カードも原作ソースに基づきます。

原作バイナリのエミュレーションではなく、次の相違・近似が残っています。

| 項目             | 現在の相違・制限                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 物理・接地・衝突 | コース頂点・法線は原作の整数生成処理と角度表を使用し、区間・セルの選択と接地面の高さは原作の整数境界判定・平面式を使用します。浮遊・着地・斜面力・速度計算・空中ロールは原作Cと直接比較済みです。機体・影の姿勢と推力更新は明示入力した行列に対して原作Cと比較済みですが、SDKの三角関数・行列生成の丸めは未照合で、GTE・固定小数点行列・機体同士の衝突の更新順序、壁応答は原作Cと直接比較していますが、機体更新全体の一致は未検証です。 |
| CPU              | 難易度別の最高速度・追加推力・進行差補正は原作を参照していますが、経路選択・旋回判断・低速時の壁回避はブラウザ版の実装です。落下後は復帰します。TRAININGでは課題別の制御を使用します。                                                                                                                                                                                                                                                  |
| 描画             | Three.jsの深度バッファ・透視補正・照明を使用します。RETROは320×240の頂点丸め、アフィンUV、RGB各5bit量子化を適用し、HDは透視補正を使用します。原作の描画順、GTEの固定小数点・投影丸め・頂点単位照明、STPビット単位の半透明やGouraud色演算は完全再現していません。                                                                                                                                                                        |
| カメラ・演出     | 原作の追従式・視点オフセットの回転・開始演出・リプレイ視点と表示時間を使用しますが、固定小数点の視点行列やすべての遷移・照明・描画タイミングの完全一致は未確認です。破片などの乱数列はブラウザ用の決定的な列で、原作と同じ配置にはなりません。SUZUKIの停止時の遷移・足の接地補正にも差があります。                                                                                                                                      |
| 音声             | SEQイベント・テンポ・楽器・VABサンプル・ループとADSR設定をWeb Audio / AudioWorkletで再生します。SPUのガウス補間、リバーブRAM演算、24音発音制限、発音タイミングの完全再現はしていません。残響は畳み込みによる近似です。                                                                                                                                                                                                                  |
| 日本語表示       | 提供素材にPS1 BIOSのROMフォントが含まれないため、HELP・スタッフなどは固定セルに配置したブラウザフォントです。原作の日本語字形・文字装飾とは異なります。                                                                                                                                                                                                                                                                                 |
| リプレイ互換     | スティックの中間値はブラウザ内では別途保持しますが、PS1形式への書き出しではデジタル方向へ変換します。実機の記録を読み込んだ場合の軌跡の完全一致は未検証です。                                                                                                                                                                                                                                                                           |
| メモリーカード   | 仮想2スロットで8KBゲームデータを扱います。実物カードの抜き差し・未フォーマット状態・通信エラーは再現していません。原作実機とのファイル受け渡しは未検証です。                                                                                                                                                                                                                                                                            |
| 2P BATTLE        | 画面分割対戦は未対応です。メニューでは対応状況を表示します。                                                                                                                                                                                                                                                                                                                                                                            |
| 成績表示         | 単独走行後のリプレイ内成績表示について、原作との表示時間・終了条件の照合が残っています。                                                                                                                                                                                                                                                                                                                                                |

提供VABのキー範囲に対応するトーンがないHOVER2（プログラム127・ノート28）、SAMPLE16（同51）、SELECT（同36/56）は、原データの範囲判定に従って発音しません。

## 開発

以下のコマンドはリポジトリのルートで実行します。開発にはNode.js 22以降とnpmを使用します。

| ディレクトリ                  | 内容                                                     |
| ----------------------------- | -------------------------------------------------------- |
| `HOVER_SOURCE/` / `HOVER120/` | 原作ソース / データ                                      |
| `src/`                        | TypeScriptソース。共通の型は `src/types.d.ts`            |
| `dist/`                       | 配信用HTML/CSS・ビルド済みJavaScript・アセット・Three.js |
| `tools/`                      | 原作データの抽出・変換ツール                             |
| `tests/`                      | ゲームロジック・アセット・コース・ブラウザの検証         |
| `extracted/`                  | 原作データの展開先（Git管理対象外）                      |

```sh
npm ci
npm run typecheck     # strictモードで型チェック
npm run build         # src/*.ts → dist/*.js
npm test              # ビルドとロジック・アセット・完走テスト
npm start             # Python 3でローカルサーバーを起動
npm run lint
npm run format:check
npm run test:source-geometry # Python 3とCコンパイラを使う原作C関数との直接比較
npm run test:source-walls    # 壁応答・整数移動・補正ループの原作C比較
npm run test:source-hover    # 浮遊・着地・落下開始・斜面力・速度・空中ロールの原作C比較
npm run test:source-tiles    # 常時床効果・落下中の床属性の原作C比較
npm run test:source-resistance # 減速・ブレーキ・32bit符号判定の原作C比較
npm run test:source-attitude # 機体・影の姿勢と推力の原作C比較（行列を明示入力）
```

ゲーム本体の編集対象は `src/` です。変更後は `npm run build` を実行し、生成された `dist/*.js` も更新してください。ビルドは配信用HTML/CSS・変換済みアセット・同梱Three.jsを削除・再生成しません。

物理・ルール・記録・トレーニングはブラウザとNode.jsテストで共有するため、TypeScriptのnamespaceからグローバルAPIとCommonJS APIを生成します。描画・音声・HUD・ゲーム画面はES modulesです。

`npm ci` / `npm install`でHuskyとlint-stagedのコミット前フックを有効にします。ステージ済みの対応ファイルにPrettierを実行し、失敗時はコミットを中止します。手動整形は `npm run format` です。

### 検証

テストは `tests/**/*.ts` にTypeScriptで記述しています。実行にはNode.js 22.18以降が必要です。Node.jsの型除去機能で直接実行し、`npm run typecheck`で本体と全テストをstrictモードで型チェックします。`npm test`にも型チェックが含まれます。テストはビルド済みの`dist/`を検証するため、個別に実行する前には`npm run build`を実行してください。

`npm run test:source-geometry` は、同梱の `MAKEMAP.C` / `LIB.C` / `CAR_CTR.C` から関数本体を取り出してコンパイルし、生成済みデータとブラウザの接地判定を比較します。全24コース・471区間の頂点96,058個と法線73,088個、およびセル境界・外壁・外側を含む107,000点の区間／セル選択・接地面高さを照合します。実行には抽出済みデータ、Python 3、`cc`が必要です。

`npm run test:source-walls` は、原作の `car_wallcheck` 本体を直接コンパイルし、全24コース・左右・速度と高さの境界・バンク・CPU・ゴール後・落下中を含む52,160ケースを照合します。さらに同じ52,160ケースで整数移動と壁補正の繰り返しを比較し、位置・慣性・ダメージ・壁距離・接触フラグ・効果音と破片の発生条件を確認します。乱数による破片の形や配置は比較対象外です。

`npm run test:source-hover` は原作の `car_gravide` / `car_bank` / `car_preope` / `car_rotation` を直接コンパイルし、浮遊・着地・落下開始・影の表示と斜面力を254,040ケース、速度を13,603ケース、空中ロールを16bit全65,536値で照合します。接地中の姿勢行列や影の姿勢、全フレームの物理・描画・音声の一致を保証するものではありません。

`npm run test:source-attitude` は、原作の `car_rotation` 全体を26,184ケース、`car_acceralate` を50,320ケースで照合します。比較には前フレームの機体・影の行列を明示入力し、角度ラップ、ラダー、床の法線との内積、旋回時のバンク、影の独立した姿勢補正、推力の整数射影・速度上限・ターボ量を確認します。SDK内部の三角関数・行列生成処理は比較対象外です。

`npm test`は物理・床効果・衝突・周回・15課題の条件・ランキング・入力リプレイ・カード形式と保存処理・GP成績の表示順を検証します。全9コースのプレイヤー、および4難易度×9コース×CPU3枠の単独3周完走も確認します（CPUは落下後の復帰を許可）。

ブラウザ検証はローカルサーバーを起動し、PlaywrightとChromiumを指定して実行します。Playwrightは開発依存に含まれています。既定のPlaywrightを使う場合は、`npx playwright install chromium`でブラウザを準備して`npm run test:browser`を実行できます。既存の環境を使う場合は従来どおり次の引数で指定できます。

```sh
npm run test:browser -- <Playwrightのモジュールパス> <Chromiumの実行ファイル> <URL>
```

同じ引数で `test:menu` / `test:postrace` / `test:credits` / `test:phases` / `test:attract` / `test:help` / `test:replay` / `test:ghost` / `test:card` を実行できます。描画・音声、各画面の進行、記録・保存、リプレイ、キーボード・仮想ゲームパッド・モバイル表示を検証します。HELP本文の原作全行照合には `extracted/` の素材が必要です。

完走・失敗・課題結果などの画面遷移テストには状態注入を使用しており、全課題を実操作でクリアした検証ではありません。物理ゲームパッドの操作感、およびPS1実機の映像・PCMとのフレーム単位比較は未検証です。

`npm run test:source-tiles` は原作の `car_chipeffect` 本体をコンパイルし、常時効果のダメージ・床ブレーキ・無照明／半透明属性とダメージ音の開始条件を29,696ケースで照合します。落下待機でも最後に選択したセルと更新前のgripを参照し、`d`・`*`・`B`を適用します。`P`・`J`・`>`・ゴールなどの侵入時効果は落下中に再発動しません。比較は常時効果の分岐に限定し、通常走行の侵入時状態機械、全体の時計と音源波形の一致を保証しません。
